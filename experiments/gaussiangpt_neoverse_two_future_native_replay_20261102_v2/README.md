# 双未来两窗口的独立原生 GS 重放

读取已经训练完成的共享 decoder 及其两套连续码，重新生成两个窗口、9 个未来时刻、运动／静止两种条件共 36 份原生 GS；每份保存两个相机视角。生成过程逐帧核对先前已审查的 PNG，并固定 decoder、codec、初态缓存和 checkpoint 的哈希。

随后在**独立进程**中只加载保存的 GS 和原生 renderer，不加载状态 codec 或 motion decoder，以相同相机重放 72 个视角，并比较保存的生产进程画面。重放一致只证明保存与加载一致，不能证明物体动作正确；范围仅为两个已训练窗口，不代表已训练 Q-Former 或全 168 窗口通过。

v1 的包生产进程因辅助文件名 `common.py` 与原生 renderer 的绑定模块同名而在导出前退出；训练未被改动。v2 使用 `replay_utils.py` 并增加模块冲突回归检查，v1 的失败日志保留。

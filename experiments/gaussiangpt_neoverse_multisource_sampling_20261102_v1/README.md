# 跨视频连续动作训练的数据调度

后续跨视频实验以完整视频源划分：两段训练视频各 177 帧、168 个相邻十帧窗口；第三段整段只作评估。第三段曾在历史实验中被观察，因此不能称为从未接触过的最终测试集。

本目录只提供确定性数据调度与聚合工具：每个逻辑 B4 由两个训练源各提供两个样本；蒸馏每轮每源覆盖 168 个窗口，联合图像监督每轮每源覆盖 168×9 个窗口／未来步。它不会将评估视频混入训练，也不把高度重叠的相邻窗口随机切成训练与验证。

连续码银行索引按 `(训练源, 窗口)` 定位，若未来使用自由码，其形状为 `[2,168,9,16]`；此处没有生成或训练任何动作码。跨源指标先对同一物理帧的多个窗口上下文求平均，再对每个视频的 176 个未来帧求平均，最后对视频等权。这样定义是为了避免窗口重叠改变加权方式，并不意味着帧或窗口是独立样本。

真正的跨源训练还需要经过审查的 decoder／教师、真实 GPU 预检、统一半径 6 下重新评估和按对象运动的验收。本目录不证明跨视频泛化。

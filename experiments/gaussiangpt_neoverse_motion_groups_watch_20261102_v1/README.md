# 阶段 B 完成后的变化分组监听器

以 Linux `inotify` 等待阶段 B 根目录的完成或失败文件，不循环查询训练进度、不使用 GPU、不向训练进程发送信号。最长等待 24 小时；失败只记录原因，不自动重试。

只有 B 已完成三个检查点的全 168 窗口评估及每个检查点 104 个 GS 包、208 个视角的独立重放，且训练记录、评估文件、重放结果及视觉检查素材的哈希均与 B 的完成汇总一致，才会对各检查点运行源画面变化分组。分组输出写在本监听器目录，不写入 B 历史目录。

输出只是评估统计。它不会自动决定教师可用，不会自动启动 C，也不能代替物体运动画面审查、同初态运动／静止对照或跨源验证。

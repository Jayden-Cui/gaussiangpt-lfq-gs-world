# 运动／静止小试的视频和逐帧审查素材

监听器只在已启动的两窗口联合诊断进程自然结束且结果、代码及来源哈希核对成功后，生成无顶标三栏视频：源视频、运动码重建、静止码重建。另生成源／运动和静止参考／静止输出的 h1–h9 逐帧接触图，便于分别检查两个分支。

监听通过 Linux 进程退出事件进行，不轮询、不占用 GPU、不向训练发信号。产物仅供后续视觉审查，不会自动判定动作正确，也不能替代独立 GS 重放或全 168 窗口实验。

v1 在监听启动前的来源核验中发现手工抄写的哈希长度不足，未启动监听或 GPU。v2 在独立目录从原实验启动记录读取完整哈希，并增加长度及格式检查；v1 的失败记录保留。

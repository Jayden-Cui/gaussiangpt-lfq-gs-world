# 阶段A：冻结9560步解码器，优化全片段连续码

## 目的和范围

测试目前9560步运动decoder是否存在容易找到的连续码，使已训练视频的主要动态恢复。使用原177帧、168个相邻10帧窗口、每窗口9个未来状态；每窗口一个独立`[9,16]`自由连续码，组合为`[168,9,16]`。初值逐项来自9560步Q-Former的正确前缀输出，不加入LFQ/FSQ或AR。

固定9560步motion decoder全部参数、GaussianGPT原codec、初态候选空间与上下文；实际训练只能更新自由码。自由码以未来真值监督进行优化，它是后验能力上界诊断，不是能够在线生成动作的编码器，也不证明跨视频泛化。

## 固定预算和覆盖

两个独立进程在相同冻结decoder下分别处理窗口0–83和84–167；它们没有共享可训练参数，最终按原窗口次序合并。每进程B4，各完成20轮完整的84窗口×9未来步遍历，即每个组合20次直接RGB监督、每组3780步，总计30240次窗口采样。每窗口是独立Adam参数；未入当前批次的窗口梯度为None，避免Adam动量偷偷更新未采样窗口。

优化沿用原状态损失与`RGB + 0.1 × 状态损失`，Adam初始学习率0.003，betas=(0.9,0.99)，梯度范数上限1。训练在5、10、20轮固定保存，每个检查点均做全168窗口、1512个未来预测和176个不同物理未来帧的评估；20轮为主结果，不根据训练集结果挑选最佳检查点。

GPU0执行前半窗口拟合；GPU1先做占据/残差诊断，再执行后半窗口拟合。完成后两GPU并行评估5/10轮，最后评估20轮；每阶段导出八个诊断窗口的图像、无顶部标记左右对照视频、104份原生GS包，并由独立renderer进程重放208个视角。

## 诊断和验收边界

占据替换在decoder预测之后执行：以真实目标格点选取**预测特征**再渲染，和预测占据结果比较；它只用于离线定位，不能作为未来在线预测。残差诊断统计真实目标特征中超出最近初态特征±3σ的比例、目标/候选格点`tanh`饱和比例及标准化特征误差下界；潜在特征不可达不直接证明图像效果不可达。

主指标对相同物理帧的不同窗口上下文先求平均，再对176帧等权。9560步Q-Former指标按相同窗口和horizon从哈希绑定的原始评估逐项取出。评估`correct`为优化后自由码，`baseline_qformer`为原9560步正确前缀码，`initial_only`为原9560步Q-Former的重复初态消融，`swapped_window_codes`使用相邻窗口的自由码。

预先固定的两个已知关键窗口颜色代理条件：目标可见帧的预测保留率≥95%，中心误差不超过目标颜色区域包围盒对角线10%的帧占比≥95%，轴角度误差中位数≤10°，不存在连续超过一帧的目标消失。它们是颜色/ROI代理，不是人工标注的完整物体轨迹；阶段结论还需审查八个动态窗口视频。全片段运动MAE改善≥10%仅作为拟合诊断，不替代主要动态验收。

若自由码不能恢复关键动态，应按文档进入阶段B：以原两个窗口成功的decoder为初值，在全部168窗口联合训练共享decoder和自由码；若能恢复，应固定对应decoder，再进行后验提取器阶段C。还需进行同初态运动/静止测试以及跨源视频划分。阶段A成功不等于动作码任务完成。

## 执行与可复现性

读取哈希绑定的9560步checkpoint、原行动码、177帧状态缓存和原评估；原目录只读。原src通过已校验的恢复助手加载，显式按路径加载新评估代码，防止同名旧模块遮蔽。CPU见证检查两个分片完整覆盖、冻结decoder仍能向自由码传梯度、因果扰动、未选择窗口的Adam动量不会漂移、合并次序和oracle占据选取。两个GPU分别执行真实B4图像反传预检后恢复原始码再正式训练。

每分片训练最多6小时，诊断最多1小时，每次完整评估最多1小时，每次重放沿用1200秒；每个worker6个CPU线程，原GPU空闲显存检查与24GiB分配上限不变。出现非有限值、来源变化、内存不足或超时则停止对应分支，保留失败证据，不自动删帧、删点或无限重试。环境沿用既有只读gaussiangpt环境，不安装或升级依赖，保留已有viewer服务。

```bash
/data/CJH/envs/gaussiangpt/bin/python -B tests.py
/data/CJH/envs/gaussiangpt/bin/python -B driver.py coordinate
```

输出：`shard_0/`、`shard_1/`为码拟合；`diagnostics/DIAGNOSTIC.json`为占据和残差诊断；`sweep_05/`、`sweep_10/`、`sweep_20/`为统一评估和冷重放；`SUMMARY.json`及`SUMMARY.md`记录结果和下一阶段提示。最终影像及物体运动必须目视审查后才能判断阶段分支。

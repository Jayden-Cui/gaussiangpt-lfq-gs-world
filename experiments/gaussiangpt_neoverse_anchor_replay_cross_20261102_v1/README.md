# 第 1 轮回放：解码器与连续码交叉诊断

回放训练在第 1 轮后两个历史成功窗口出现动作退化。本诊断固定初态与状态 codec，只推理、不训练，在这两个窗口的 18 个未来状态上比较四种组合：

1. 原成功解码器 + 原成功连续码；
2. 原成功解码器 + 回放第 1 轮连续码；
3. 回放第 1 轮解码器 + 原成功连续码；
4. 回放第 1 轮解码器 + 回放第 1 轮连续码。

四个条件各有 18 个预测，必须复现原来两组配对的预览指标。两个交叉组合可能处于对应解码器未见过的码分布，只能定位与退化相关的环节，不能单独断言因果，也不能代表整个 168 窗口或未见视频。

`protocol.json` 绑定真实训练检查点和原始 codec。程序复用已通过的旧诊断汇总与预览校验，仅在当前进程中配置四条件，不修改历史代码。独立使用 GPU 1，显存分配上限 12 GiB，启动前需要至少 32 GiB 空闲；不更新权重，不向回放训练发信号。逐帧图与无顶部标记视频从左到右为源图及上述四个条件；颜色区域结果只是运动代理，需人工检查。本诊断不执行独立 GS 冷重放。

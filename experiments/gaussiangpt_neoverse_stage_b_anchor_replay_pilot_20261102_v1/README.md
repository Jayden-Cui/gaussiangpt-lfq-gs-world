# 阶段 B 的关键窗口重放：有界匹配试验

两个已知窗口在第 5 轮退化，而同轮 decoder 在单视频全部 168 个窗口的 h9 上改善了其他窗口。这个试验从同一个第 5 轮 checkpoint 恢复 decoder、168 组码和 Adam 状态，对比：

- `control`：原目标，189 次更新；
- `anchor_replay`：同样的 189 次更新及主样本，每次额外加入一条窗口 35 或 123 的真实监督，权重 0.1。

每个分支的主样本覆盖 168 个窗口中的 756 对窗口／未来步，按固定规则每窗口取 4 或 5 个未来步、每个未来步覆盖 84 个窗口。这是为了控制计算量的半轮试验，不是完整阶段 B；两个分支的主样本和优化器初态完全相同，重放分支多使用监督与计算。

分支完成后对两个关键窗口全部 18 个未来状态及全 168 窗口 h9 做推理比较，并输出八个固定窗口的静帧。预设的数值判断是锚点 18 帧误差至少比对照低 10%，高变化组 h9 误差不高于对照的 1.05 倍；同时报告物体颜色代理和画面，不能自动当作正式教师验收。完整预算、失败边界和局限见 `protocol.json`。

这不改变正在运行的原阶段 B，不训练 Q-Former，不包含 LFQ／FSQ／AR。混用真实未来监督的自由码仍然是离线诊断；没有完整 168×9、独立 GS 重放或跨视频证据。

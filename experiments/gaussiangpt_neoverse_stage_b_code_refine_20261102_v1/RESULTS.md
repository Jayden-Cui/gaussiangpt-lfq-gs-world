# 固定阶段 B decoder 的两窗口连续码补充优化

**只优化动作码未恢复关键动作。** 在固定 B 第 20 轮 decoder、原 codec 与初态条件后，两个窗口的运动加权误差小幅下降，但最终黄条仍断裂、绿梁仍消失。该结果支持继续调整共享 decoder 的训练过程；它不证明任何更长优化或其他初始化都不可能成功。

训练从 B 第 20 轮对应的两组 `[9,16]` 自由码开始，沿用 B 的图像／状态损失和码学习率，但 Adam 状态重新初始化。每步同时训练两个窗口的一个跨度，40 轮各遍历 h1–h9，共完成 360 次 B2 更新；真实 GPU 梯度预检的更新已丢弃。decoder、codec 和初态输入保持冻结，没有量化、Q-Former 或未来真实占据输入。

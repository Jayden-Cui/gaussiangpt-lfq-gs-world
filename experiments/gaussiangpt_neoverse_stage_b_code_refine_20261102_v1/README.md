# 阶段 B 后的两窗口自由码补充优化

阶段 B 第 20 轮的两个关键窗口仍退化。目标占据替换诊断显示，占据选择在部分帧影响明显，但其他帧仍无法恢复。为了区分「当前固定 decoder 的码尚未充分优化」和「只调整码仍不够」，本实验固定 B 第 20 轮 decoder、原始 GaussianGPT codec、初态条件与输入状态，只更新窗口 35 和 123 对应的两组连续码。

起点严格使用 B 第 20 轮配对 checkpoint 中的码，损失沿用 B 的图像和状态损失；每步各训练两个窗口的同一预测跨度，九个跨度随机打乱后均衡遍历 40 次，共 360 次有效 B2 更新。优化器使用新的 Adam 状态；因此这是固定 decoder 下的有限预算可达性诊断，不能将其严格解释为只改变训练步数的单因素实验。预设第 90、180、360 步评估两个窗口的全部 18 项未来预测，最终还要看逐帧图像；不以最好检查点替代固定末步。

真实未来格点只参与损失监督，不进入 decoder 输入；不使用占据 oracle、量化或 Q-Former。实际启动前，校验完整阶段 B 评估、绑定 checkpoint、独立重放、上一项占据诊断以及本实验代码；GPU 预检验证图像梯度到达两组码，然后丢弃预检更新并恢复初值及优化器。任何异常停止并保留错误，不自动重试。

即使两个窗口恢复，也只说明有限预算下当前 decoder 有能力通过特定码恢复这些训练窗口，不能证明全部 168 窗口已通过，更不能直接作为 Q-Former 教师。若两窗仍无法恢复，应继续调整共享 decoder、监督或训练策略，并重新进行全片段验收。

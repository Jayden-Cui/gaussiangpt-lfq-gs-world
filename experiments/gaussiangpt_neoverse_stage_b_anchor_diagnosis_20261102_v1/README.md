# 阶段 B 两关键窗口的占据与特征诊断

阶段 B 第 20 轮的全段运动加权误差下降，但黄条断裂、绿梁在运动时大幅消失，不能作为 Q-Former 教师。先固定该轮 decoder 和自由码，对原先两个成功窗口的 18 个预测进行诊断，避免直接把失败归因于某一个模块。

每帧比较四列：源画面、B 预测占据与预测特征、**只在推断结束后**用真实目标格点筛选 B 的预测特征、真实未来状态经原 codec 重建。真实目标特征只用于统计，不进入替换占据后的重建；真实目标格点是不可用于推断的 oracle。每帧同时统计目标特征是否超出原有 `F0 ± 3σ` 范围、预测 `tanh` 的饱和比例。输入、模型、完整评估和独立重放均按哈希绑定，模型与 codec 不训练。

如果目标格点替换后主要物体明显恢复，占据选择可能是重要因素；如果仍未恢复，说明仅换目标格点不足，需要继续调查预测特征、解码与优化。任何结果都不能单独证明某个结构的理论容量上限。诊断仅覆盖两个训练窗口，不能代表完整 168 窗口。

本目录 `tests.py` 是占据替换逻辑的 CPU 合成测试；仅在 `DIAGNOSIS.json` 正式生成并经过画面检查后，才能报告实际诊断结果。

# 真实目标格点替换诊断

两段视频均为左右对照：左侧是原始视频；右侧首帧是初态 codec 重建，后九帧是冻结的 9560 步模型预测特征，在预测完成后使用真实未来状态的格点位置选取并渲染。后九帧使用了真实未来位置信息，只能用于离线定位，不能当作模型实际预测或动作码训练成功的视频。

- `s035_source_vs_oracle_5fps.mp4`：黄条窗口，第 35 至 44 帧。
- `s123_source_vs_oracle_5fps.mp4`：绿梁窗口，第 123 至 132 帧。
- 同名 `frame_00` 和 `frame_09` 图片是两个窗口的首帧与末帧。

视频为了便于观察以 5 fps 慢放；源数据仍按原视频约 29.97 fps 取相邻帧，每个 10 帧窗口从首帧到末帧约 0.300 秒。

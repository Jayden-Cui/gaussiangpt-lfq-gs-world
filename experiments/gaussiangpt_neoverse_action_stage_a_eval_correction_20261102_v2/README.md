# 阶段 A：重复初态对照的独立修正

原 `free_z` 评估器误将“重复初态”预测复用为优化自由码预测。该错误不影响自由码优化、正确码指标、换码指标或占据诊断，但原初态对照的指标、图片及其 GS 包均无效。

9560 步原始评估已独立计算同一 decoder、同一 codec、同一初态、同一真实相机下的重复初态码并完成原生 GS 冷重放。此目录核对这批动作码与新评估保存的初态码逐元素完全一致，并核对相同 `(窗口, horizon)` 和真实目标状态指标，然后逐项引用先前真正计算出的初态指标、占据指标和末帧原生 GS 包。修正图片只替换错误的第三栏；同时将它与先前冷重放参考图像逐像素核对。自由码输出和其他条件保持原记录。

程序使用 Linux pidfd 的退出事件等待原协调器自然结束，不暂停、不终止、不重启、不修改任何原有进程或文件；原协调器失败时停止修正并保留失败信息。一个先前尝试使用 SIGSTOP 接管的独立实验发现 `screen` 会自动恢复协调器，该尝试已中止，未触碰训练子进程。其记录保存在相邻的 `gaussiangpt_neoverse_action_stage_a_eval_fix_20261102_v1` 目录。

```bash
/data/CJH/envs/gaussiangpt/bin/python -B tests.py
/data/CJH/envs/gaussiangpt/bin/python -B correction_supervisor.py
```

修正结果写入新的 `sweep_05/`、`sweep_10/`、`sweep_20/` 与 `SUMMARY.json`，保留原始结果的哈希与来源。原目录中无需标记的原视频与自由码对照视频第一、二栏没有受此错误影响。修正不代表主要动作已经恢复；仍需审核视频并按证据选择阶段 B 或阶段 C。

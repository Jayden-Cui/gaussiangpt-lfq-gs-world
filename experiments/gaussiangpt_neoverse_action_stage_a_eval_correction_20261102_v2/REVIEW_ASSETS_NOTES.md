# 阶段 A 运动画面审查准备

最终修正评估完成后，`review_assets.py` 可将八个固定诊断窗口的 h0、h3、h6、h9 画面整理为无顶部文字的对照图；每个小图左侧为原始视频，右侧为自由码重建。它记录输入图片与评估文件的哈希，但不会自动判定动作成功。

`REVIEW_ASSETS_TEST.json` 仅用合成图片检查裁切、时间顺序和八窗口覆盖。真实审查图尚未生成，仍需结合完整视频、运动指标和关键物体轨迹决定进入阶段 B 或阶段 C。

`contact_supervisor.py` 已启动，使用进程退出事件等待修正评估自然完成，再生成这些审查图。它不向原训练或评估进程发送信号，也不自动选择后续训练分支。

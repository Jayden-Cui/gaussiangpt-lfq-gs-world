# 两窗口同初态运动／静止 Q-Former 试验

固定已完成双未来自由码训练的同一个 decoder：Q-Former 对真实未来前缀提取运动码，对重复 S0 的因果前缀提取静止码；两种码均为 `[9,16]`，decoder 只接受相同的初始条件与对应连续码。前置时空特征使用已有冻结缓存，这是针对 C0 路线的两窗口诊断，不是全 168 窗口正式 C0/C1/C2 对照。

每次逻辑 batch 包含两个窗口各自的运动、静止四种样本，逐样本累积梯度。先进行 600 次归一化自由码蒸馏，再进行 594 次码／状态／渲染联合更新；后一阶段 h1–h9 各覆盖 66 次。静止状态图像目标由 S0 与同一时刻相机产生，配对运动 codec 参考只用于静止损失权重和离线评估，不传入 decoder。

固定教师已完成 36 份 GS 包、72 视角独立重放，粗运动／静止画面经两窗口检查；黄色条运动中心颜色代理的 h3 为目标尺度 10.81%，略超预设 10%，因此这套教师只用于本诊断，尚未作为完整 168 窗口教师验收。测试包括各分支重建、与自由码教师的逐时刻比较、前缀因果性、最终 Q 输出的原生 GS 冷重放及逐帧审查。无 LFQ、FSQ 或 AR；本试验不能证明跨视频泛化。

# 两窗口双未来 Q-Former：启动与零步对照

训练已绑定两窗口双未来自由码 checkpoint、对应的逐帧视觉审查、36 个 GS 包／72 视角的独立重放，以及原状态缓存。此教师仅用于两窗口机制诊断：黄色条 h3 的中心颜色代理略超预设阈值，不能据此声称全片段教师已通过。

CPU 检查覆盖 600 次蒸馏、594 次联合更新的四条件均衡及 9 个 horizon 各 66 次覆盖。真实 GPU 预检分别检查两个窗口的运动与静止 RGB 损失，四种条件均能向 Q-Former 的 query 和投影传播非零梯度；两次预检更新已撤销，posterior 和优化器重新恢复，decoder 与 codec 保持冻结。[预检记录](result/PREFLIGHT.json)

第 0 步，旧 Q 直接接入新 decoder 的运动区域 MAE 为 0.081095，自由码教师为 0.031369；Q 静止码对静止参考的加权 MAE 为 0.110460，自由码教师为 0.007583，18 帧中有 6 帧更接近静止参考。教师重新渲染与既有结果的逐项最大误差为 5.22×10⁻⁷。[零步逐帧数据](result/step_00000/EVALUATION.json)

现已启动 1194 次更新：先蒸馏，后加入状态与渲染监督；最终自动检查原始未来状态扰动下的前缀因果性，并在独立进程中冷重放 Q 输出的 36 份 GS 包、72 视角。启动时协调器 PID 为 773492、训练子进程 PID 为 773493；这是启动快照，最终效果与人工视觉审查尚未完成。该试验不训练可迁移动作先验，也不替代全 168 窗口的正式 C 对照。

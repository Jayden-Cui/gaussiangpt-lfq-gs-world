# 初态条件下学习未来空间支撑

上一轮提供真实未来坐标后，两个终帧的主要物体姿态可由冻结 codec 恢复。本轮取消解码器对未来坐标的依赖，检验共享运动解码器能否用初态和低维连续码预测未来的占据集合及 64 维特征。

## 输入、结构和训练边界

- 使用两个完整相邻 10 帧 TRAIN 窗口 `35…44`、`123…132`，覆盖 20 个不同物理帧、18 个未来状态。不是全 177 帧正式训练。
- 每个窗口独立连续码 `[9,16]`，两窗口合计 `[2,9,16]`；经原 `16→64` 投影进入 native-64 时空 decoder。码是联合优化的自由变量，不由 Q-Former 生成，不运行 LFQ/FSQ；下一阶段才能检验 posterior 编码与离散化。
- 复用原始初始化、四尺度/四 block 解码骨干、位置相关动作分支、初态归一化和因果时间卷积。初态 encoder 冻结，只从 `S0` 计算四个上下文槽。GaussianGPT 原始状态 codec 全部冻结，保持 eval / float64 decoder，输入输出特征宽度仍为64。
- 从完整 `C0` 加上固定半径4的整数立方邻域产生候选坐标。半径3在两个 TRAIN 窗口的覆盖核查中漏了一个中间帧格点，因此在优化前确定半径4。候选构造函数没有未来输入；运行后不根据目标增补候选，不截断目标或候选。
- 候选特征从最近初态格点复制；初态隐藏上下文同样转移。新几何分支输入相对初态最近格点的3维位移及是否原本存在的1维标记，投影为64维。
- 新占据头输出 `[9,N_candidates]` logits。初始化按初态占据给±2先验；head从零开始。推理使用固定 `logit>0` 选择支撑，不使用目标点数、top-k 真值数量、未来坐标并集或真值强制保留。
- 未来特征为最近初态特征加 `3*std(frame0)*tanh(residual_head)`，保持上一轮验证可行的边界。`h0` 直接保留原初态；未来为可变 `[M_h,64]` 加整数坐标。

## 配对能力测试

两臂 `free16` / `fixed16` 在相同初始化、相同更新次序和预算下分别训练。free16 的每窗口码可学习；fixed16 始终把零连续码送入 decoder，学习相同其余模块，作为初态和时序结构是否已足以记忆样例的对照。参数保存时两组公共初始化必须一致，fixed16 的码参数不更新。

每臂 1200 次优化器更新，逻辑 batch 为两个完整窗口，通过逐窗口反传累积梯度实现，不减少窗口帧数：

1. 前600步：未来占据的正/负平衡 BCE + 真值占据格点上标准化特征 L1。目标仅参与损失。
2. 后600步：每次两窗口各渲染一个未来 horizon，固定轮流1…9；原全图/手部ROI/运动 RGB 损失 + 0.1倍上述状态损失。所有渲染都用预测支撑。硬选择的离散梯度由显式占据监督补充。

Adam，lr从0.001余弦降到0.0001，betas=(0.9,0.99)，梯度范数上限1，参数见 protocol.json。第600/1200步保存 checkpoint，固定最后一步验收。工程预检有两次丢弃更新并精确回到共同初值；第一次零输出头阻断上游重建梯度属预期，第二次必须检查 decoder/动作码的非零梯度。

## 评估与停止条件

两窗口全部10帧保存图像，未来18帧同时评估正确码、交换窗口码以及真实未来状态参考；记录预测节点数、支撑IoU/precision/recall、图像指标、关键帧颜色区域指标。固定码组交换操作应保持等价。相邻视角只和既有 NeoVerse 教师渲染比较。

保存所有正确预测的 native GS 及关键终帧换码/参考包，并在独立、不加载 codec 的进程重放。潜在状态也保存后重建检查。5fps对照视频展示完整窗口慢放，原视频约29.97fps。重放一致性不能当成对真实视频的画质指标。

此轮成功只证明两个已知训练窗口的 decoder 容量及条件依赖，不能证明物理动作语义、跨场景迁移、Q-Former压缩、LFQ或AR成功。固定码组和换码结果必须同时报告。科学失败不自动触发延长训练、扩大半径或调参。

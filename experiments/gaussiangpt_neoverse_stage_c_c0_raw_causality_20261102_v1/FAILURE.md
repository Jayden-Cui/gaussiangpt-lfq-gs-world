# V1 真实缓存检查失败及定位

V1 使用原 GPU 生成的缓存、在 CPU 重算两个窗口的时空 memory，先在窗口 35 的 h1 因最大特征误差 `0.0020675659 > 0.00005` 退出；没有模型训练、优化器更新或结果验收。V1 没有生成通过见证，也不能用于正式评估。

随后对两个窗口、运动／重复初态两种输入的九个 memory 比较：CPU 同进程重复重算逐元素一致，但与缓存相比的最大特征误差最高为 0.0039473，最大动作码差为 0.00002597；用 GPU 重算时，同样 36 组 memory 和对应码与缓存逐元素一致。该结果表明此前严格 CPU／GPU 逐元素比较不可直接作为缓存错误证据；没有进一步断定具体浮点算子或底层内核的原因。

原始状态未来扰动检查仍须独立完成。V2 改用 GPU 按正式评估的设备与同一容差运行，而不是放宽验收阈值。

# 数据接口核验

服务器 CPU 测试逐文件校验三段视频的 531 份连续状态和 531 份原图／相机缓存；每段分别抽查起点 0、80、167 的完整 10 帧窗口，确认坐标、64 维特征、图像、相机、帧次序和约 29.97 fps 的时间间隔。

`buildingblock_tower_14_0` 通过训练接口读取时正确报错。该片段在以前的实验中已经被观察过，因此这一划分可用于避免训练／验证按重叠窗口混淆，不能称为未接触过的最终测试集。

三个视频使用与当前实验相同的原始连续 GaussianGPT codec，摘要为 `a1c32dbcb29d23da9bc65cbf16cc49d40cdb36954952b8ac91580fd3eeeb2917`。测试只涉及数据读取与完整性，没有对这些数据进行新的动作码训练或跨视频动作评估。

# 多视频连续动作数据接口

该准备接口读取三段各 177 帧的 Neoverse／GaussianGPT 数据：`tower_17_176` 与 `tower_10_176` 为训练源，`tower_14_0` 只允许以 `purpose='eval'` 读取。历史记录显示第三段以前已经被评估和观察过，因此它不是从未接触过的独立测试集。

逐帧读取原始 codec 产生的连续稀疏状态，形状为坐标 `[N,3]`、特征 `[N,64]`，以及真实图像 `[252,448,3]`、相机 `[2,4,4]`、内参 `[4]`、两视角参考图像和时间戳。每个 10 帧窗口保留 `t→t+1` 相邻帧和原始采样时间；任何样本均在读取前验证状态与原图／相机缓存的哈希。

拆分以整段源视频为单位；评估源不能通过训练接口读取。此处只完成数据绑定与访问控制，不代表动作码已在其他视频上训练或取得泛化结果，也不引入 LFQ、FSQ 或 AR。

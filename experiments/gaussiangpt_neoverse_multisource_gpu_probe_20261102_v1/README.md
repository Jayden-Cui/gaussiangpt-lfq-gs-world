# 第二训练视频的半径 6 GPU 管线检查

该工程预检使用第二段训练视频的真实相邻帧 26–35；该窗口已知有目标格点超出半径 4。预检只从首帧构造半径 6 候选及 decoder 条件，使用每个真实前缀生成连续 `[9,16]` 后验码，并检查渲染和图像损失到码的梯度。未来状态只提供后验输入和监督，不进入 decoder 初态条件。

原 9560 步 Q-Former、运动 decoder 和原 GS codec 全部冻结，不执行优化器更新，不读取评估视频。该窗口只用于检查真实数据的内存、形状和梯度可行性；它不是阶段 B 教师结果、跨视频泛化测试或训练成功证明。第二视角没有原实验的有效区域掩码，指标使用明确标出的整图参考，不能与旧掩码指标混为一谈。

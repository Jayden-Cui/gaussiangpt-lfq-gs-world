# 第二训练视频的真实未来状态 codec 参考

对上一项第二训练视频 26→35 帧的 GPU 管线检查，读取同一目标帧的真实未来稀疏 GS 状态，以相同相机和原始 GaussianGPT codec 渲染。由此分别观察原视频、旧 Q-Former 预测状态的渲染、真实未来状态经过 codec 的渲染，避免将所有跨源误差归因于动作码。

真实未来状态仅作为离线重建参考，不能用于在线预测；不更新模型，也不读取评估视频。完整图像 MAE 与历史绑定的同帧 codec 记录进行核对；该单帧诊断不代表跨视频动作泛化评估。

前一独立 v1 目录保留了两次已定位的工程失败：历史状态字段实际为 `evaluated`，以及独立进程缺少已绑定的 native bridge 模块路径。v2 对实际元数据和 bridge 来源均增加 CPU 检查，再执行 GPU 参考渲染。

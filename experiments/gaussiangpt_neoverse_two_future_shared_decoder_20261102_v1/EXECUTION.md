# 启动与零步复现

服务器 134 上，固定采样的 CPU 测试和真实历史码／评估哈希绑定已通过。实际 GPU 预检中，运动分支 RGB 损失传到运动码和 decoder 特征层的梯度范数分别为 0.004009、0.048399；静止分支分别为 0.039404、0.179569。预检只执行一次临时成对更新，随后已恢复 decoder、两组码和优化器；状态 codec 与初态编码保持冻结。

第 0 步的运动源图像运动区域 MAE 为 0.02977625，逐项复现历史原始自由码的最大误差为 3.73×10⁻⁹；静止输出复现上一项 540 步诊断的最大逐项误差为 2.24×10⁻⁷。两个分支使用同一初态条件和对应相机；静止目标来自 S0，同相机真实运动参考仅用于静止损失的区域权重和离线评估。

已启动 360 次成对更新。启动时协调器 PID 为 770028、GPU 子进程 PID 为 770054；作业不向主训练发送信号。此记录对应启动快照，数值门槛与逐帧动态审查仍待训练完成，当前不能声称运动／静止控制成功或已经训练 Q-Former。

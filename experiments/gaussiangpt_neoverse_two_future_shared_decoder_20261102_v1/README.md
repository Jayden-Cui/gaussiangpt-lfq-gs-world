# 两窗口同初态运动／静止：共享 decoder 与自由码诊断

固定 decoder 的 540 步静止码优化未能稳定保留物体。本实验用旧两窗口 decoder 作为起点，让同一 decoder 分别读取两套可优化连续码，重建同一初态对应的真实运动序列和静止序列。运动码从原自由码初始化，静止码从前一诊断的第 540 步码初始化；GaussianGPT codec 和初态编码／候选空间保持冻结。

每次更新选择一个窗口与时刻，同时等权训练运动和静止两个分支，共 360 次更新，每种窗口／时刻组合各 20 次。静止目标是同一 S0 在目标相机下的 codec 图像；为了强调配对动作涉及的区域，静止损失的权重由该时刻真实运动 codec 参考与静止参考的图像差计算，这一真实未来信息只作为离线训练权重，不输入 decoder。评估固定初态、相机，比较两套码及对应参考，并检查原运动是否退化。

此为**双窗口离线自由码容量诊断**，不训练 Q-Former，不是全 168 窗口教师，不做量化或 AR；有限预算失败不证明理论不可能。数值门槛、显存与时长上限、失败停止条件见 `protocol.json`，物体保留及黑色残影必须另做逐帧审查。

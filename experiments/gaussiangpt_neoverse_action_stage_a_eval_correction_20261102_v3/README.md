# 阶段 A 对照修正 v3

v2 已逐项生成三个检查点的重复初态修正结果，但在汇总时错误地用整个 `[5,10,20]` 列表作为字典索引，导致监督程序失败；原训练和正确自由码评估均已完成，未被改动。v3 在独立目录修正最终检查点索引为 20，并增加实际调用 `main()` 的三检查点汇总测试；不覆盖 v2 的失败记录或任何原始实验文件。

修正依据完全相同 decoder、codec、缓存、初态、相机和重复初态动作码的历史独立评估，逐条替换 1512 个窗口预测中的错误 `initial_only` 指标、支撑和诊断图第三栏；自由码与其他条件保持原值。对应原始重复初态 GS 包被标记无效，修正清单引用历史独立重放通过的原生包。

通过真实数据绑定、CPU 控制替换测试、单检查点完整链路测试、三检查点主流程测试后，才在本目录生成修正评估。八窗口接触图只用于人工动作审查，不自动判断成功；修正完成也不意味着整个动作编解码任务完成。

## 新发现：手部加权区域对绿梁覆盖偏低

原渲染损失为全图 MAE＋手部 ROI MAE＋`10/9` 倍运动区域 MAE。手部 ROI 固定为 `[0,35,180,252]` 和 `[265,25,448,252]`。绿梁搬运到上方中央时经常离开这些区域；`object_proxies` 的绿色物体框只用于评估，没有作为独立物体重建损失。

用原固定颜色掩码统计，9 个未来帧中绿梁平均占画面的 1.18%，平均只有 24.15% 的绿色像素在手部 ROI 内：

| 未来步 | 绿色像素落入手部 ROI 的比例 |
|---|---:|
| h1 | 94.53% |
| h3 | 35.58% |
| h5 | 1.36% |
| h6 | 0% |
| h7 | 0% |
| h9 | 7.63% |

这不意味着绿梁没有监督：全图、运动区域和状态特征损失仍覆盖它。按当前 RGB 损失的逐像素系数归一化，绿色区域平均分得约 1.56%；这只是系数质量占比，不能视为真实梯度贡献或已经证明的根因。

后续可对固定预算下的物体区域监督进行对照，同时保留 decoder 占据与特征检查。当前证据不支持通过重做整套绿梁数据、增加相同回放或直接责怪 Q-Former 来解决问题。

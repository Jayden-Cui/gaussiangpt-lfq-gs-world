# CPU 准备结果

已从两窗口自由码实验加载精确的 1200 步运动解码器，并核对权重摘要 `ffcadefe1fb9fc19c6e5257664c88198d3b087f25b913ab2b434c038ea5ab899`；自由码次序确认为起点 35、123。对其他窗口，初始化采用同一时期、与该 decoder 配对的 Q-Former，而非 9560 步模型的码。

这只是 CPU 功能见证，尚未验证原生渲染损失的 GPU 梯度，也没有执行阶段 B 正式训练或取得全片段教师结果。正式是否运行应先依据阶段 A 的完整动态结果判断。

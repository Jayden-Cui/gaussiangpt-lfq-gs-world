# 阶段 B 的条件准备：共享解码器与自由连续码

该目录只准备训练核心与 CPU 检查，不自动启动阶段 B。先等阶段 A 的修正评估和主要运动画面完成，只有其自由码仍无法恢复关键动态时才实际进入 B。

采用同一经过两窗口成功验证的 1200 步 motion decoder；初态编码器、候选空间、上下文和原 GaussianGPT 状态 codec 保持冻结。每个训练窗口有独立 `[9,16]` 连续自由码，168 个窗口共享同一个可训练 motion decoder。初始化使用与该 decoder 同一数值坐标系的旧 Q-Former；两个已知窗口 35 和 123 直接使用该 decoder checkpoint 内的已训练自由码，防止把 9560 步模型的不兼容码坐标系误当作教师。

训练使用完整窗口与未来步覆盖，B4 梯度累积；沿用原图像/运动加权损失和 `0.1 ×` 状态损失。不同窗口使用独立 Adam 参数，避免未采样窗口因优化器动量漂移。后续正式运行前仍需写入单独锁定的预算和评估协议，通过真实 GPU 上的图像到码及解码器的梯度预检，并为两窗口和全片段保存可审查动态结果。此准备不代表已经训练了全片段教师。

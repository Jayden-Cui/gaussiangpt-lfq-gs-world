# 阶段 B 训练入口：版本 3

如阶段 A 的最终画面审查确定需要阶段 B，应使用 `b_worker_v3.py`；评估与重放仍使用 `b_evaluate_v2.py`。版本 3 读取 CPU 预先生成的 168 组初始码，并核对 decoder、Q-Former、原始 codec、状态缓存、代码哈希和两个历史成功窗口的自由码。它不会把 9560 步模型的码误用到两窗口 decoder 上。

`WORKER_TEST_V3.json` 在 CPU 上读取真实初始码并验证两个锚点及错误收据拒绝；阶段 A 的审查输入使用合成记录测试。真实 GPU 预检和阶段 B 训练尚未启动。旧训练入口保留供追溯。

# 阶段 B 的全片段评估准备

`b_evaluate.py` 与 `evaluate_b.py` 针对完成的阶段 B 检查点，准备 168 个窗口、1512 个未来状态的评估、两个旧成功窗口回归、因果 decoder 扰动、无顶部标记的视频和独立原生 GS 重放。每种待解码码都单独送入 decoder。

参考条件有明确边界：旧 9560 步 Q-Former 的指标来自不同 decoder，只是同数据、同 codec 的历史参考；“重复初态”码来自两窗口 Q-Former，并不是独立受训的阶段 B 初态模型。自由码本身仍是使用真值优化的离线容量诊断，不是可部署的动作编码器。

`EVAL_TEST.json` 记录 CPU 合成测试，覆盖不同码的独立解码、历史参考绑定、重复记录检查、初态码提取和两个窗口颜色代理。另验证了独立原生重放的导入路径不会加载 codec 或 MinkowskiEngine。尚未对真实阶段 B checkpoint 运行 GPU 渲染、原生 GS 重放或画面审查。

这些新增脚本的哈希由 `EVAL_TEST.json` 单独记录；正式阶段 B 运行时应在新目录将其与训练代码统一锁定。

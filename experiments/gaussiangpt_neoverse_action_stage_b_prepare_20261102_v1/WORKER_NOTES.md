# 条件训练入口

`b_worker.py` 提供共享 decoder 与 168 组自由码的训练工作入口；它要求配置固定覆盖与预算，并检查经人工或实验执行者审查的阶段 A 最终修正评估明确选择阶段 B。这个检查不要求用户再批准已经授权的实验。

真实运行前会重新绑定两窗口成功 checkpoint，保持 35、123 两组原始自由码，使用配对 Q-Former 初始化其他窗口，并执行 B4 原生渲染梯度预检；预检后恢复 decoder、自由码和优化器。训练检查点同时保存 decoder 与对应自由码，不能把不同 checkpoint 的码混用。

`WORKER_TEST.json` 记录的是合成审查文件上的启动条件与采样测试，不是正式训练结果。GPU 预检、阶段 B 训练、完整视频评估和教师验收均尚未执行；训练结束本身也不会自动声称阶段 B 成功。`b_worker.py`、`worker_tests.py` 及其测试哈希在 `WORKER_TEST.json` 中单独绑定，正式运行时应在新实验目录中统一锁定代码清单。

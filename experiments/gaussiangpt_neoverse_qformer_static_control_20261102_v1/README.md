# 历史两窗口 Q-Former：同相机运动／静止控制

此前保存的两窗口 Q-Former 实验包含真实未来前缀码与重复初态码；后者有时仍解码出接近真实运动的画面。初态和未来帧的相机参数并非逐位相同，所以本检查将真实未来 GS 状态与重复的初态 GS 状态都用**同一个未来帧相机**、同一个冻结原 codec 渲染，再分别比较两种已保存 Q 码的解码结果。

对每个未来帧，以两个 codec 参考图之间的变化构造权重，报告运动码和静止输入码分别更接近哪个参考。每段无标记视频从左至右为：源画面、真实未来 GS 的 codec 参考、真实未来前缀码输出、静止 S0 的 codec 参考、重复 S0 码输出。

两种 Q 预测必须逐帧复现原实验图像误差；缓存状态哈希、模型和相机均需匹配。结果只覆盖此前训练过的两个窗口，是阶段 D 的先行诊断，不代表新的阶段 C 模型、跨源泛化或在线预测。此任务在已有 GPU 1 重放小试的进程退出后，通过 pidfd 事件启动，不轮询或向该进程发送信号。

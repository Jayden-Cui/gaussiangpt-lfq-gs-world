# 历史两窗口 Q-Former：同相机静止控制结果

## 实验和结果

对窗口 35 和 123 的每个未来时刻，分别将初始 GS 状态 S0 与真实未来 GS 状态 Sh 用**该时刻同一相机**、同一个原 GaussianGPT codec 渲染，得到静止和运动两个参考；再把历史实验保存的真实未来前缀码、重复 S0 码送入同一个冻结运动 decoder。以下是 18 个未来帧的运动区域加权 MAE，越低越接近相应参考：

| Q-Former 输入 | 对运动参考的误差 | 对静止参考的误差 |
|---|---:|---:|
| 真实未来前缀 | **0.026302** | 0.161243 |
| 重复同一个 S0 | **0.029009** | 0.159765 |

在 18／18 个未来帧中，重复 S0 码的输出对运动参考的误差小于对静止参考的误差。两个 Q 输出在变化区域的平均差为 0.013633，而两种 codec 参考在相同权重下的平均差为 0.164810；这些差值受手部、物体、颜色和遮挡共同影响，并不是单独的三维运动量。

历史两种 Q 预测相对于旧评估逐帧复现：72 个误差项最大差为 1.86×10⁻⁹。测试没有训练更新；重复初态码来自旧实验保存的控制输入，不是新训练的静止码。

## 画面审查

两个窗口各 h1–h9 的逐帧图已逐一查看：静止参考中的黄条保持初态横放，重复 S0 码的输出却呈现黄条抬起并逐渐转竖；静止参考中的绿梁保持初始手持位置，重复 S0 码的输出仍将绿梁移向两根柱子上方。两段画面还包含手部模糊，细节并非完全相同。

## 能得出的结论

**此前成功的两窗口 Q-Former＋decoder 组合没有通过同初态运动／静止控制。** 即使后验只看到重复 S0，这两个窗口仍产生了接近原运动轨迹的画面。因此，两窗口重建成功本身不足以证明动作由码可控。

这不能单独归因于 Q-Former 没有读取未来：真实未来码与重复 S0 码的数值确实不同，历史实验中换码和零码也会改变结果。静止序列未作为该模型的训练目标，重复 S0 码可能位于 decoder 不熟悉的分布；可能涉及码的组织方式、decoder 对这些码的响应、初态／时间捷径或它们的组合。需要进一步区分 decoder 是否存在可解码的静止码，以及后验能否从静止输入产生它。

这是两个已训练窗口、单一视角的图像域诊断，不是新的阶段 C 模型、在线动作预测、跨源泛化或独立原生 GS 冷重放。[逐帧数据](result/STATIC_CONTROL.json)和[图像哈希](result/MONTAGES.json)记录了来源及核验范围。

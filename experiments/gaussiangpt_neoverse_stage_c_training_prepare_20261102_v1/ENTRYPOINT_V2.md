# 阶段 C 训练入口：版本 2

正式训练应使用 `c_train_driver_v2.py` 和 `c_worker_v2.py`。版本 2 采用 `teacher_receipt_v2.py`：除 decoder、连续码、数据来源和运动画面审查外，还检查 1512 条窗口预测完整、没有未来几何输入，并要求 104 份原生 GS 包的独立重放通过，其中 80 份正确码包逐一通过。

若按计划比较“只加时间”和“时间＋变化”，应使用[匹配共享时间投影的新入口](../gaussiangpt_neoverse_stage_c_matched_initialization_20261102_v1/RESULTS.md)：它调用上述版本 2 底层流程和相同教师验收，但消除两个设置的共享时间投影初始权重差异。配置需明确绑定初始化策略；仍须在真实教师选定后进行 GPU 预检。

阶段 A 的原初态对照包存在已记录的标签错误；教师验收只使用其经过独立重放的正确自由码包，初态对照来自修正后的评估记录。训练配置和其保存副本分别记录哈希，C0／C1／C2 共用 Q-Former 初始化摘要，C1／C2 的复制编码器初始摘要也单独记录。

`RECEIPT_TEST_V2.json`、`WORKER_TEST_V2.json` 和 `TRAIN_DRIVER_TEST_V2.json` 均为 CPU 功能见证。三种结构已完成使用合成教师码的 GPU 梯度预检；真实教师尚未选定，绑定真实教师的 GPU 预检和正式后验训练尚未开始。旧入口保留供追溯，不应作为正式训练入口。

教师的 `major_motion_usable` 是依据画面及动态指标填写的人工审查结论，不由收据校验器从视频自动推导。建立收据前，应核对同一 checkpoint 完整评估的 `STAGE_METRICS.json` 中两关键窗口的逐帧保留、中心、主轴和连续缺失记录，结合至少八个固定窗口的画面审查；不得仅因为 1512 条预测与冷重放齐全，就将运动标记为可用。当前预先登记的颜色／区域代理门槛为可见帧保留率和中心误差合格帧比例各至少 95%、主轴角度误差中位数至多 10°、最长连续漏检至多 1 帧。颜色代理只是辅助：若它与画面或物体真实状态不一致，需要有可复核的独立分割或跟踪证据并说明偏差，不能仅以颜色代理失败或通过代替动态审查。

补充：已有[颜色代理尺度敏感性检查](../gaussiangpt_neoverse_object_proxy_sensitivity_20261102_v1/RESULTS.md)发现，源画面的少量离散同色像素会扩大目标边界框，使归一化中心误差偏小。审查时应检查掩码碎片和遮挡，并保留原预登记结果；最大连通区域也可能丢失被遮挡物体的其他部分，不能自动充当真值。

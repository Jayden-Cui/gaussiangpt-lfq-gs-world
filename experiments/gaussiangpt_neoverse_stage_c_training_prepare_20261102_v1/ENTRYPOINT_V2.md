# 阶段 C 训练入口：版本 2

正式训练应使用 `c_train_driver_v2.py` 和 `c_worker_v2.py`。版本 2 采用 `teacher_receipt_v2.py`：除 decoder、连续码、数据来源和运动画面审查外，还检查 1512 条窗口预测完整、没有未来几何输入，并要求 104 份原生 GS 包的独立重放通过，其中 80 份正确码包逐一通过。

阶段 A 的原初态对照包存在已记录的标签错误；教师验收只使用其经过独立重放的正确自由码包，初态对照来自修正后的评估记录。训练配置和其保存副本分别记录哈希，C0／C1／C2 共用 Q-Former 初始化摘要，C1／C2 的复制编码器初始摘要也单独记录。

`RECEIPT_TEST_V2.json`、`WORKER_TEST_V2.json` 和 `TRAIN_DRIVER_TEST_V2.json` 均为 CPU 功能见证。真实教师尚未选定，真实 GPU 预检和后验训练尚未开始。旧入口保留供追溯，不应作为正式训练入口。

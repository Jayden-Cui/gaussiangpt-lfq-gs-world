# 阶段 C 训练入口

`c_train_driver.py` 在得到正式教师后构造 C0／C1／C2，核对相同的 Q-Former 初始参数、同一 decoder／codec／状态缓存和教师收据，固定采样及训练配置，再调用 `c_worker.py`。C1、C2 从 decoder 的初态编码器复制一份独立后验编码器；训练时不会更新 decoder 的初态编码器。

服务器 CPU 检查使用实际两窗口模型验证三组 Q-Former 初始权重一致、C1／C2 编码器副本初始权重一致，以及固定种子下 C2 初始化可复现；结果见 `TRAIN_DRIVER_TEST.json`。该见证不包含正式教师或训练，也不替代真实 GPU 图像梯度预检。

入口使用阶段 B 准备目录中的一次性 GPU 线程初始化，并要求教师来自经过运动审查的完整实验。正式阶段 C 启动前仍需在新目录冻结全部代码、训练预算和具体教师收据。

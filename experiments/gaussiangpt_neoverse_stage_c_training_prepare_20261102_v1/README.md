# 阶段 C 的固定教师训练准备

此目录提供三种后验版本共同使用的完整采样器、教师绑定校验和训练工作函数；不会自动选教师或启动训练。阶段 A／B 必须先形成经过主要运动画面审查的 decoder＋自由码配对，并对 168 个窗口、1512 个预测完成评估。

教师收据绑定 decoder checkpoint、连续码、完整评估和运动画面审查的 SHA-256，同时核对 decoder 参数摘要、原始 codec、状态缓存、窗口顺序与 `[168,9,16]` 形状。动态审查由实验执行者完成，不意味着需要用户额外授权。尚无合格配对时，训练函数不能启动。

所有 C0、C1、C2 实验应传入相同的教师、随机种子、完整窗口采样和训练预算。第一阶段按窗口蒸馏全部 9 个码，第二阶段均衡遍历全部窗口／未来步并加入状态和渲染监督。正式 GPU 训练前，工作函数在四个真实窗口检查图像梯度到 Q-Former、可训练时空编码器（如存在），再恢复模型及优化器初态。

此处尚无固定训练预算、正式教师、阶段 C GPU 结果或运动／静止验收结果；这些必须在阶段 A／B 的实际结果确定后产生。

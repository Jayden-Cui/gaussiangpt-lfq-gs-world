# 阶段 C 准备核验

CPU 测试使用隔离临时目录构造合成 decoder、连续码和评估记录，验证教师权重摘要、码顺序、逐文件哈希、评估来源和运动审查绑定；量化码、未通过运动审查的教师与被修改的码文件均被拒绝。合成数据仅用于功能检查，不是正式教师。

同一采样器对各版本生成可复现的 B4 训练顺序：蒸馏阶段每轮覆盖 168 个窗口，联合监督阶段每轮覆盖 168×9 个窗口／未来步。测试同时确认缺失组合会被拒绝。

正式训练函数在开始前仍要求一个真实、已经审查的教师配对，并在实际 GPU 上检查图像损失到 Q-Former 和可训练后验编码器的梯度；预检更新会丢弃并恢复模型与优化器。当前未运行该 GPU 预检、未开始 C0／C1／C2 正式训练，也未验证运动／静止控制。

# 现有多视频 codec 的可复用性审计

复核已有的原 codec、只微调解码器和完整微调 codec 三个版本；它们均使用相同来源数据的既有评估，后两者在两段训练视频上各追加 300 次更新。该审计不训练模型，不选取评估视频的逐帧记录、不加载其状态或图像，也不替换当前阶段 B 使用的原 codec。原始元数据文件物理上包含三个来源。

首先从实际 checkpoint 逐张核对编码器侧张量，而不是只读取训练记录；再对两段训练视频各 177 帧的稀疏状态按世界 XYZ 坐标对齐并比较特征。稀疏张量的数组行顺序可能变化，不能将两份数组第 `i` 行直接相减。

固定帧 0、44、88、132、176 生成无顶部文字的对照：每行依次为参考、原 codec、只微调 decoder、完整微调 codec。原视角的参考是源视频，附近视角的参考是 teacher 渲染，并非实测真值。结果只描述状态重建与潜在状态数值，是否适用于 LDM 仍需重新评估动作解码、梯度和原生 GS 重放；不能声称跨场景动作泛化。

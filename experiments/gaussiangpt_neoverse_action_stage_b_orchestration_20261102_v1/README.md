# 阶段 B 条件执行流程

本目录准备阶段 B 的协调器；它本身不决定阶段 A 是否成功，也不启动训练。只有阶段 A 的最终修正评估和至少八个窗口、包括黄条与绿梁的动态审查明确给出 `stage_B`，并将真实审查哈希填入预先固定的配置后，才可启动。

协调器先启动一次真实 GPU 预检与 20 轮训练；训练完整结束并核验三个成对检查点后，在两块 GPU 上分别评估并独立重放第 5、10 轮，再评估和重放第 20 轮。它还为八个固定窗口生成无顶部标记的接触图，便于检查物体运动。每个阶段有固定时限和独立日志；出错后记录失败，不自动重试，也不自动判断主要物体运动是否成功。原始 codec、初态编码器与 context 的冻结验证由训练 worker 执行。

汇总中的运动误差是单条训练视频上的自由码结果，不能当成已训练的后验编码器、跨视频泛化或在线动作预测。训练、视频审查与同初态运动／静止控制仍需实际完成。

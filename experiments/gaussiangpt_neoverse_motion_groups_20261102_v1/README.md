# 按源画面变化强度分层评估

冻结的 GaussianGPT 状态 codec 和单段 177 帧视频对应 168 个窗口。为了在阶段 B 的全片段评估完成后单独报告高变化窗口，本工具只从真实图像计算每个窗口的变化强度，按从小到大分为四组，每组 42 个窗口。每窗口得分是 9 个未来帧相对初态的全图像素变化强度平均，公式见 `protocol.json`；相同分数按窗口起点排序。

分组只用于离线评估，真实未来不会送入预测器；分组创建于 B 训练进行期间，并非 B 启动前预注册。画面变化包含手部移动、遮挡及光照变化等，不能等同主要积木运动，也不作为动作成功率。正式验收仍须结合两个已知窗口的颜色区域代理、其余代表性窗口画面和原生 GS 重放。

`motion_groups.py freeze` 对已绑定的真实帧缓存生成分组；`evaluate` 要求全部 168×9 对窗口及帧索引完整，并对各组提供每预测等权、先按物理帧聚合再等权、h9 单独等权三种数值。评估器兼容阶段 A/B 的不同历史 Q 对照命名，但不把它们混为同一 decoder 下的消融。任何不完整、重复、源不匹配或非有限结果会报错。

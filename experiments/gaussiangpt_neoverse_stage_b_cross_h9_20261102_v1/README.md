# 第 5 轮跨 decoder、跨码的全窗口 h9 诊断

在同一条训练视频的 168 个窗口上，固定最远未来步 h9，将成功起点和第 5 轮的 decoder 与自由码做 2×2 交叉，共 672 次预测。对每个窗口与条件使用同一初态、目标图像和原 GaussianGPT codec，不进行优化器更新。h9 的 168 个目标帧恰好各不重复；额外按已冻结的源画面变化四分位单独报告。

此前两个窗口的 8 个 h9 交叉结果必须逐项复现。真实未来状态经原 codec 的参考指标从已绑定的修正阶段 A 评估读取，不进行未来预测。输出的八个预先固定窗口图只用于视觉检查，不能代替完整的时间连续性或独立 GS 冷重放。

混合训练时点的 decoder／码可能超出联合训练分布。即使覆盖全部窗口，这也仅是单条训练视频、一个未来步上的离线自由码诊断，不是最终阶段 B 评估、Q-Former 推理或跨源泛化。

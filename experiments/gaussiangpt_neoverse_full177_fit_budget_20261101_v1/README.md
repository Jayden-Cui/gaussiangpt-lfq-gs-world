# 全177帧固定预算拟合诊断

上一轮两组均完成2000步和全窗口评估，但明显运动的黄色长条、绿色横梁仍有丢失与拖影。真实前缀组运动MAE=0.075142，独立受训初态组=0.076111，真实未来状态codec参考=0.029464。本轮检查已训练视频能否继续拟合，以及真实动作前缀的收益是否增大。

## 固定方案

- 数据仍为同一177帧TRAIN视频的全部168个相邻10帧窗口，没有未见动作划分。
- posterior和initial_only两组分别恢复各自2000步末态，包括完整Adam一阶/二阶矩与步数；学习率继续保持末步的0.00003，不重启、不重新热身。
- 两组各追加20轮完整的168窗口×9未来步遍历。每轮1512个组合打乱、每批4个，共378次更新；追加7560次更新，累计9560步。
- 每个窗口/未来步恰好追加20次直接RGB监督，原来的3–5次增至23–25次。每个窗口累计采样227–228次；仍在每次更新中对全部9个未来状态计算原状态损失。
- 除采样交错方式和继续训练预算外，损失、模型、初态候选、原codec、冻结状态编码器和64维隐藏空间保持原实现。Q-Former输出连续码[B,9,16]，不加入LFQ/FSQ/AR。
- 本轮同时改变了未来步的交错顺序，因此结论应表述为“固定预算继续拟合诊断”，不把结果变化完全归因于步数单一变量。

## 固定评估与停止条件

累计3890、5780、9560步分别对应新增5、10、20轮，均保存权重并执行相同完整评估；最终9560步为主结果，不按训练结果择优挑选checkpoint。每阶段、每组覆盖1512项窗口预测、176个不同未来帧，导出8段诊断视频和104份原生GS包。训练结束后由独立进程完成每阶段208次视角冷重放；中间阶段的重放在训练结束后执行。

主指标对同一物理帧的不同上下文先平均，再对176帧等权。固定报告相对本组2000步的运动误差变化、两组差距、初态输入消融、换码、支撑IoU，以及35→44和123→132末帧颜色代理。诊断标记为：运动误差改善至少10%、真实前缀相对受训初态优势至少10%、拿掉后续输入误差增加至少10%、两个关键末帧颜色代理IoU均至少0.5。它们是诊断条件，不能代替逐帧动作质量检查，也不会触发自动加训或切换LFQ。

任一分支出现非有限损失/梯度、冻结权重变化、来源不匹配、超出资源或时限即停止该分支，保存证据，不自动重试、删帧、裁点或改参。训练预算8小时；单worker含三次评估总墙钟上限9小时；每次评估沿用10800秒上限，每次重放1200秒。预计正常训练及评估约5–6小时，具体取决于实际渲染速度。

## 执行与来源

复用134服务器已有gaussiangpt环境，spec保持不变；不安装依赖、不修改环境文档。两组分别绑定GPU0、GPU1，每进程6个CPU线程，至少32GiB可用GPU显存、24GiB分配上限；共享只读完整缓存，各worker在CPU保留一份。现有viewer服务保留。

原始模型、更新函数、评估函数及冷重放函数均从已冻结的full177实验按明确路径加载；恢复函数来自已通过导入冲突回归检查的eval_resume实验。新目录保存独立CODE清单和continuation.json，旧训练、旧评估、原始数据与权重保持只读。

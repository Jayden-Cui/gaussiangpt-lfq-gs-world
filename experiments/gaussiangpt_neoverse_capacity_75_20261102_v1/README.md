# 75 服务器：动作码与运动 decoder 维度对照

用户确认动作码 16→64、LDM 内部特征 64→128，GaussianGPT 状态 latent 维持每格点 64 维。所有服务器侧代码、环境、数据、临时文件和结果位于 `/data/CJH/1`。

已用四张 RTX 4090 各启动一组：`z16_w64`、`z64_w64`、`z16_w128`、`z64_w128`，见 [启动核验](STARTUP_CHECK.json) 和 [执行记录](EXECUTION.md)。当前阶段使用全 168 个窗口的自由连续动作码与共享运动 decoder，定位表示容量；不训练 Q-Former，不使用 LFQ、FSQ 或 AR。

四组来自相同第五轮 checkpoint，数据为同一段 177 帧相邻 NeoVerse 状态。冻结原 GaussianGPT codec 和初态 context。宽度扩展覆盖运动 decoder 的空间、因果时间、位置调制、归一化和输出映射，输出仍为 `[N,64]` 状态特征。新增通道必须有有效梯度，不能仅补零后声称扩容成功。

状态、源数据与历史模型绑定、初始解码行为、前缀因果性、真实 GS 渲染反向传播和显存检查均已通过。四组使用相同原始损失、同一第 6／7 轮采样序列，各追加 846 次 B4 更新；统一重新初始化 Adam，避免把扩维后的不同动量迁移方式混入比较。没有加入 134 另一轮实验的新物体损失。

每组完成后自动评估全部 1512 个未来预测、176 个物理未来帧，保存八窗口共 72 份正确码预测 GS 并独立重放 144 个视角，另导出 177 帧双栏视频与黄条／绿梁慢放视频。全片段视频采用确定的窗口选取规则，使用真实未来优化得到的码，不是 AR 滚动预测。结果仍需检查动态物体是否持续存在、位置与姿态是否正确，不能仅依据均值或重放一致性验收。

# 真实未来坐标 + 自由特征诊断

上一轮在初态支撑 `C0` 上直接优化未来特征，有界/无界各 600 步后，黄条仍破碎，绿梁没有恢复。此轮保持同一份完全冻结的原始 codec、完整分辨率、损失、Adam 参数、学习率与预算，把优化支撑换为已知真实未来坐标 `Ch`，继续检查空间支撑和 native 生成路径。

## 唯一新增输入与特征初始化

本轮使用真实未来坐标，属于诊断性的 oracle 条件；它没有预测 occupancy。特征初始化函数只接受 `C0, F0, Ch`，没有 `Fh` 参数：

- 同一世界坐标格点同时存在于 `C0` 和 `Ch` 时，复制该位置的 `F0`。
- `Ch` 新增的格点，复制欧氏距离最近的初态格点特征；并列距离按 XYZ 字典序选择。整数 CPU 距离计算避免浮点平局差异。
- 保留 `Ch` 的全部坐标及输入顺序，没有把逐帧 GS/潜在行号当作物理点对应，也不声称最近邻是物体轨迹。
- 保存逐目标格点的初态来源索引、完整初始化状态、最近邻距离和来源 SHA。未来特征只用于真实未来状态直接解码参考。

第 44 帧参数由上一轮 `834×64` 变为 `863×64`；第 132 帧由 `875×64` 变为 `933×64`。支撑大小和特征排列都随坐标变更，所以结果不能解释为完全排除了初始化与参数量影响的纯坐标因果效应。

## 四组固定实验

`35→44` 和 `123→132` 各运行有界/无界两组，每组 600 步。设映射后的初态特征为 `F_init`，有界为 `F_init + 3σ*tanh(R/(3σ))`，无界为 `F_init+R`。`σ` 仍是原片段第 0 帧的通道标准差。两组零残差独立初始化，Adam 学习率 0.1 余弦下降到 0.01，使用原始真实视角的全图、手部 ROI 与运动加权 MAE，相邻视角仅评估。

与上一轮一样，Q-Former、运动 encoder/decoder、动作量化均不参与。codec 全部参数与缓冲区冻结、保持 eval，保留原硬剪枝，decoder 为 float64、状态为 float32。每轮的原始 source GS 与潜在支撑均完整使用。

旧结果按 `previous_run` 中的协议、代码清单、汇总及包清单 SHA 绑定；`core.py` 原样复用，已通过的损失/指标测试不重复运行。`support.py` 的新检查覆盖精确交集、最近邻、并列规则、输入/行序不变性和重复坐标拒绝。

## 输出、验收和解释

每端点保存真实初/终帧、保持初态、映射后的初始化、真实未来状态参考、两组第 0/100/300/600 步的图像，以及最终完整特征和 native GS 包。主对照图依次是：真实目标、真实未来状态直接解码、上一轮初态支撑无界结果、本轮未来支撑有界结果、本轮未来支撑无界结果。额外初始化对照图展示坐标变更后优化前的效果。

工程验收：四组完成固定预算；真实渲染梯度有限非零；初始化严格来自 `F0`；codec 参数/缓冲区不变；共 10 个 native GS 包、20 个视角在独立进程重放通过，MAE≤1e-5 且 PSNR≥60。重放不是画质指标。

科学验收仍需人工判断黄色条是否完整竖起、绿色横梁是否正确横跨两柱。颜色区域中心/主轴/IoU 是辅助量。若未来支撑明显改善，会增强对固定初态支撑的怀疑；若仍失败，继续考虑初始化、硬剪枝、native 生成与图像优化条件。失败不等于不存在解。终帧拟合不代表完整运动、动作压缩、AR 或泛化成功。

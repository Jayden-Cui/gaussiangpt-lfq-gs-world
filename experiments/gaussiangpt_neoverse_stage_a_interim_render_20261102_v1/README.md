# 阶段 A 中间渲染结果

只整理已完成渲染和原生 GS 独立重放的第 5、10 轮；第 20 轮与最终动态审查仍在进行。每个检查点覆盖同一条训练视频的 168 个相邻窗口、1512 个未来预测；总体指标先按同一物理帧平均，再对 176 个未来帧等权。

`correct` 是直接依据真实未来优化的连续自由码；它不是 Q-Former 的新预测，也不是在线预测。`baseline_qformer` 是固定的原 9560 步后验输出；`actual_target` 是真实未来状态经原 codec 的参考；`swapped_window_codes` 是自由码换窗对照。

原评估器的 `initial_only` 条件存在已记录的复用错误，故该汇总完全不引用它。其独立修正安排在阶段 A 全部原评估结束后进行。两个关键窗口的 HSV／ROI 颜色区域只是一种代理，不是人工标注的物体轨迹或三维姿态。

```bash
/data/CJH/envs/gaussiangpt/bin/python -B collect.py
```

图片和视频的左侧为源视频，右侧为自由码重建；视频以 5 fps 慢放，源视频约 29.97 fps。不可将该结果解释为使用了真实未来格点的占据替换诊断，也不能由其推断跨视频泛化。

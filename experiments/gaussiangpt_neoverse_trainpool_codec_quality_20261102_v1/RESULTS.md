# 50 段训练片段的原状态 codec 质量记录

服务器已有训练池完成收据：50 个片段、19 个文件名来源组，每片段记录 177 个相邻帧。此前的动作多源接口实际只登记了其中两段。本次从绑定的历史记录复核了全部 8850 条训练帧的图像指标，没有把它们加入 LDM 训练。

所有片段对应原 codec checkpoint `a1c32d…`。49 段的冻结 codec 摘要、原权重收据及每段质量文件已核对；当前主训练片段 `tower_17_176` 使用同一 codec 的历史逐帧评估。以下 MAE 比较同视角状态 codec 重建图和源图，越低越好：

| 统计口径 | MAE |
|---|---:|
| 当前主训练片段 `tower_17_176` | 0.016599 |
| 50 片段均值的中位数 | 0.081199 |

以 0.05 为**描述性阈值**，49／50 段的片段平均 MAE 高于该值，逐帧为 8615／8850。该阈值不是动作成功或粗解码验收标准。训练片段之间可能来自同一来源视频、并且时间重叠；逐帧和逐片段数字不能当作独立试验，来源组也是由文件名推断而来。

这个结果表明当前片段的原状态 codec 重建质量在该训练池中明显偏好。它提示跨来源实验前需要核实状态 codec 在其他训练来源的可用性，而不能仅凭当前片段通过就认为状态底座已适配整个训练池。**图像 MAE 不能单独证明物体运动错误或无法恢复**；之前对第二训练来源的[实际参考画面](../gaussiangpt_neoverse_multisource_codec_reference_20261102_v2/EXECUTION.md)显示存在颜色错置，但不能把该单例直接外推到全部片段。

该分析只读取质量 JSON 与绑定收据，没有重新加载 8850 个状态或图像文件、没有生成新的重建、没有使用 GPU，也没有评价动作码或选择验证集。训练池历史收据不能代替后续数据加载、动态视觉检查和重放。当前阶段 B 保持原单视频 codec 与既定预算；后续若调整状态 codec 或空间归一化，必须为受影响片段重新绑定／评估状态和动作模型，不能直接沿用旧教师结论。

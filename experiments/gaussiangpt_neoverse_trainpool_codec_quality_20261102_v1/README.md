# 已有训练池的原状态 codec 重建指标

本检查只读取既有 50 段 TRAIN 片段的逐帧图像指标及其哈希绑定收据，核对每段 177 帧和原连续 codec 权重；没有重新加载图像或状态、执行渲染、更新模型、读取评估片段指标或自动筛选训练数据。49 段取已有准备质量记录，当前主训练片段 `tower_17_176` 取同一 codec 的历史逐帧记录。49 段源图片级指标与旧摘要须在既定容差内一致。

输出分别汇报片段等权和来源组等权，避免某一组包含更多重叠片段时被误当作更多独立来源。MAE 超过 0.05 仅作描述性计数，并非照片级或动作验收门槛。结果用于了解下一阶段扩展前的状态重建差异，不证明动作码质量、跨视频泛化或新鲜状态重放。

当前阶段 B 的单视频训练、codec、数据划分和预算不受此分析改变。

# GPU 工程预检结果

2026-11-02，在阶段 B 使用第一块 GPU 训练期间，三种后验结构依次在空闲的第二块 GPU 上完成真实稀疏状态与渲染反向传播预检。它们均使用逻辑 batch size 4，逐样本累积梯度；这不是四个样本同时驻留的原生并行 batch。

| 结构 | 蒸馏更新耗时 | 联合更新耗时 | 峰值已分配显存 | 检查结果 |
|---|---:|---:|---:|---|
| C0：冻结 memory＋Q-Former | 0.94 秒 | 2.94 秒 | 6.48 GiB | 查询与码投影梯度非零 |
| C1：可训练时空编码器＋Q-Former | 4.89 秒 | 8.57 秒 | 6.38 GiB | 编码器输入、时空骨干、查询及投影梯度非零 |
| C2：C1＋时间与变化 | 5.21 秒 | 9.72 秒 | 6.39 GiB | 在 C1 基础上，时间和变化投影梯度也非零 |

每种结构执行一次合成码蒸馏更新和一次图像／状态联合更新，并额外核实图像损失向 Q／编码器的梯度；随后恢复初始模型并销毁优化器。原 decoder 和 GS codec 始终冻结。测得的显存和耗时仅对应这四个测试窗口、当前模型及 GPU 状态；真实训练可能不同，不能视为吞吐或显存上限保证。

预检码是原 9560 步 Q 输出加固定扰动，只为检查梯度，不是经过阶段 B 审查的真实教师。没有训练出可用的后验动作码，没有评估动作恢复或泛化。阶段 B 的全片段教师和正式阶段 C 仍未完成。

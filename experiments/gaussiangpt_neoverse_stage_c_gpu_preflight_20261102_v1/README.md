# 阶段 C 的 GPU 工程预检

在阶段 B 尚未产生可靠教师时，本工具只检查 C0、C1、C2 的真实稀疏状态输入、逻辑 batch size 4 的图像反向传播、必要参数梯度和峰值显存。它固定原 9560 步 decoder 与原 GS codec，并以原 Q 码加固定扰动作为合成梯度目标；该目标不是自由码教师，损失值和画面不能解释为动作质量。

每个变体分别执行一次合成码蒸馏更新和一次图像／状态联合更新，验证梯度后恢复初始参数并销毁优化器；不保存训练权重，不影响正在进行的阶段 B。正式阶段 C 必须等待经过动态审查和原生 GS 重放的真实教师，再按同一教师进行对照。

三个预检在空闲的第二块 GPU 上顺序执行，每个最长 300 秒；启动前检查与阶段 B 的第 5 轮预览有足够时间间隔。任何预检失败都会记录具体原因并停止该预检流程，不影响阶段 B 或自动重试。

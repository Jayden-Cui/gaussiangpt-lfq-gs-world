# 后验编码器阶段的候选模块

该目录为文档的阶段C准备独立、可验证的模型组件；尚没有可靠的全片段自由码教师，也没有开始阶段C训练。

- C0：沿用9560步Q-Former结构与已有冻结前缀memory。
- C1：复制原时空编码器的`input`与`encoder_backbone`，从原始GS状态逐前缀重新计算可微特征；不读取`detach`后的memory作为训练输入。副本与decoder初态编码器不共享参数。
- C2：C1基础上提供显式时间和按世界格点对齐的占据/特征差分。时间、差分可以单独开启，以分别检查时间信息与变化信息的贡献。消失位置的token保留到其已知前缀中，不通过GS数组行号配对。

所有变体保持每个未来步一个64维query、输出16维连续码；单窗口输出`[9,16]`，不进行LFQ/FSQ。每个h只计算S0…Sh，训练支持非重入梯度检查点以减少多前缀激活内存。后续训练时需要与同一个经过验收的自由码教师和冻结decoder绑定。

`variant_tests.py`使用实际9560步模型权重和小规模合成GS状态检查：C0复现原Q-Former，C1在初始权重时复现C0；更改后续状态或增加后续坐标不影响早期码；世界格点差分与行顺序无关，消失节点保留；C1/C2的代码损失能更新复制的时空编码器、Q-Former及相应时间/变化投影，而原decoder保持冻结。时间单独开启时不会额外引入消失token。

这些CPU检查只验证实现边界与梯度，不是全数据训练结果、画质或可迁移动作的证据。阶段A完成后，若其教师不满足主要动态恢复条件，先执行文档阶段B，再训练这里的后验变体。

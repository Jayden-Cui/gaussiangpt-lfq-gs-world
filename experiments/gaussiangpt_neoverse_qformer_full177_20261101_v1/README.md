# 全177帧：连续Q-Former与受训初态对照

按用户最新纠正，先扩大动作训练覆盖，再评价已经训练过的动作阶段。本轮使用现有搭积木TRAIN视频全部177帧、全部168个相邻T10窗口；没有新增未见动作测试或同视频训练／测试切分。两组都接受全部动作阶段的真实未来状态和图像监督。

## 两组配对实验

- posterior：Q-Former第h个查询读取真实S0…Sh前缀。
- initial_only：从训练开始，后验只读取重复S0的十个时间槽；时间戳保留，后续状态内容不作为模型输入。

两组从同一份上一轮free16空间解码器与Q-Former连续码1200步权重开始，使用同一窗口顺序、优化器、预算。两组各一张A100：GPU0／GPU1。initial_only是实际训练的初态基线，不是将训练好的posterior临时盲化，也不是未训练过对应动作的模型。

原GaussianGPT codec及状态时空编码骨干冻结。联合训练Q-Former、9个64维query、位置投影、64→16投影、运动decoder骨干、16→64投影、特征／几何／占据头。状态仍是[M_t,64]和整数坐标，动作码[B,9,16]；没有512维中间接口。旧的每窗口自由码参数保持冻结，不被forward或optimizer使用，不引入窗口ID嵌入。

## 数据完整性及缓存

source为同一原始codec产生的177个独立时刻状态。窗口start=0…167，步长1，每窗S0…S9；缓存保持全部状态格点、448×252图像和native GS支持。CPU覆盖审计显示半径4候选可覆盖所有168窗口，无目标遗漏；候选仍只由初态生成，不按未来补点。

每个后验查询独立构建自己的真实前缀并运行冻结状态时空骨干；不会先构建整窗未来几何再裁剪。前缀实现逐字复用上一轮已通过因果、变长batch和梯度测试的代码及来源哈希。准备进程在新目录生成168份只读CPU缓存，保存全部条件、真实／初态前缀、监督及177帧图像来源。两训练进程只读共享文件，各自内存缓存；不改旧环境、数据或实验产物。

## 预算与损失

每组2000次更新，有效B4，通过逐窗口梯度累积实现；不是把窗口切短。前500步占据平衡BCE及标准化64维特征L1，后1500步加入全图、手部ROI、运动加权RGB及0.1倍状态损失。没有扩展窗口的自由码蒸馏目标。

168窗口按固定seed打乱逐轮遍历，4窗一批，每窗最终访问47或48次。每个窗口有独立渲染计数器，按h1…h9循环，确保每个未来h至少被渲染监督3次。两组完全相同。Adam lr0.0003余弦至0.00003，betas=(0.9,0.99)，grad clip1，固定最后2000步，不选最好checkpoint。

GPU正式训练前做两次丢弃更新，使用0、56、112、167四窗；验证真实RGB梯度到达query、64→16投影及运动特征头，再恢复共同初值。codec与冻结状态编码器保持原值。前缀缓存数值不随运动decoder更新而失效。

## 评估范围

每组评估所有168窗口×9未来状态，共1512项窗口预测，覆盖176个不同未来物理帧。统一比较正确输入、同模型只给初态、交换窗口码（固定偏移84），以及真实未来状态codec参考。primary结果先平均同一物理帧的多个窗口上下文，再对176帧等权平均，同时保留窗口预测等权指标，避免中心帧重复加权。另列四段时间区间，不将它们冒充人工动作标签。

固定诊断窗口0、35、56、84、112、123、140、167导出完整慢放和两端原／相邻视角对照。每组导出104个GS包、208次独立视角重放；保存实际浮点动作码并读回用于解码，检查checkpoint及潜在状态读盘。所有窗口都计算指标；导出视频子集不等于训练或评估删帧。

本轮目标是已训练阶段的连续动作表示与重建。仅初态／换码影响作为诊断报告，不用于要求模型掌握未训练动作；不据单视频拟合宣称新视频泛化、可迁移动作语义或AR成功。NeoVerse及既有codec的上游训练／重建上下文也不能因本轮窗口协议而被称为新的独立测试。

# 冻结空间解码器，接入Q-Former连续动作码

上一轮仅初态候选的空间解码器能够在两个已知训练窗口恢复主要黄条／绿梁运动，直接优化的连续码比零码基线更好。本轮固定该free16组1200步权重，单独检验后验编码器能否从状态产生可用的动作码。

## 固定输入和维度

- 原始NeoVerse搭积木177帧中的35–44、123–132，两个完整相邻10帧TRAIN窗口，20个物理帧、18个未来状态。逻辑batch为2，逐窗口反传累积，保留原分辨率448×252和全部格点。
- 每个状态为整数坐标[M_t,3]和连续特征[M_t,64]。原GaussianGPT codec、状态时空编码骨干、已学习的空间解码器、候选几何支路、占据头及16→64投影全部冻结。
- 每个h单独构建S0…Sh的前缀坐标并集并运行冻结的因果时空骨干，缓存完整64维key。未来Sh+1…S9的坐标和特征不参加较早前缀的构造。缓存只用于节省冻结骨干的重复计算。
- 沿用9个64维query、9套原有Q-Former后验模块、64维位置表示。第h个query读该前缀所有有效状态格点，输出[B,9,64]，通过可学习的64→16投影得到[B,9,16]。保留原有16→64 decoder入口，不引入512维中间接口。
- Q-Former、query、位置投影及64→16投影可训练。后者以固定seed、std=0.01初始化，其余从上一轮未更新的原后验权重复制。没有可学习的每窗口码或窗口ID输入。
- decoder仍只接收S0生成的半径4候选、初态上下文和9个连续码。后验可看当前目标状态，是编码／重建任务，不是未知未来的预测或AR。

## 训练与对照

1. 600步自由码蒸馏：匹配上一轮两个窗口的[9,16]自由码，MSE按这些TRAIN码的固定均方值归一化。
2. 600步重建：真实视角全图／手部ROI／运动加权RGB损失，加0.1倍占据及64维特征监督，再加0.1倍归一化码MSE；每次两窗口各渲染一个h，依次循环1…9。梯度穿过冻结decoder和codec到达Q-Former。

Adam学习率0.0003余弦降至0.00003，betas=(0.9,0.99)，梯度范数上限1，固定1200步结果，不挑选最好checkpoint。两步实际GPU预检更新丢弃后恢复准确初值；检查RGB单独对最后query及64→16投影的梯度非零。

完整18个未来状态统一比较：Q-Former连续码、上一轮自由码参考、后验只看重复S0、同decoder零码、交换两窗口的Q-Former码，以及真实未来状态codec参考。初态重复控制保留全部10个时间槽和时间戳，仅后续状态内容替换为S0。上一轮分别训练的fixed16不是本轮同decoder零码，二者不能混同。

## 验收和运行

新增CPU检查使用实际原有64维骨干和Q-Former：未来特征及新坐标扰动不能改变更早码；初态控制不读取后续状态；变长batch的padding不会改变输出；query可反传，teacher参数无梯度，不执行量化器。

工程验收包括1200步、checkpoint重载码一致、浮点码保存／读回、潜在状态读盘重建、30个native GS包／60次视角独立冷重放。每窗生成5fps完整慢放和两端原视角／相邻视角对照。重新计算自由码参考，必须与上一轮对应帧指标在1e-5内一致。

数值保持门槛在训练前固定：平均全图及运动MAE不超过自由码参考的1.10倍；平均支撑IoU及两个端点颜色IoU各不降低超过0.05。另行报告初态控制、换码控制是否各使运动误差提高至少10%。这些门槛与视觉审查分别记录，不作为自动进入下一轮的授权；后者不足也不能宣称动作码利用了变化信息。两个训练窗口、单次seed不能支持跨视频泛化或可迁移动作语义。

本轮不执行LFQ、FSQ、ID重建或AR。只有后续验证连续后验码可用后，才单独评估LFQ损失。

运行目录：`/data/CJH/AGS-V6Direct/outputs/gaussiangpt_neoverse_qformer_support_20261101_v1`。
环境按protocol记录的既有spec/ledger只读复用，不安装或升级依赖。GPU0一张A100，6CPU线程；至少32GiB实际空闲，allocator上限24GiB；保留已有viewer等服务。训练10800秒、评估1800秒、冷重放600秒上限，失败停止，无自动重试或缩数据。

部署后CPU检查一次，通过后冻结CODE.sha256并一次提交：`screen -dmS gg_qformer_support_20261101 bash run.sh`。后台coordinator顺序运行训练、评估、冷重放、汇总；模型不轮询等待。根STATUS和qformer_continuous/STATUS提供状态，完成后SUMMARY.json/SUMMARY.md汇总。仓库不包含状态缓存和权重，不能独立离线运行。

# 冻结前缀 memory 的运动／静止输入差异

检查了当前 Q-Former 试验绑定的两个窗口、各 h1–h9 的状态缓存和前缀 memory。比较均按整数世界格点对齐，不按数组行号或 Gaussian 身份配对；下面的 memory token 包含前缀中多个时刻出现的格点。

| 窗口与未来步 | 间隔 | 重复初态 memory token | 运动前缀 memory token | 共享格点上的平均特征相对 RMS 差 |
|---|---:|---:|---:|---:|
| 黄条 h1 | 0.033 秒 | 1,668 | 1,657 | 0.415 |
| 黄条 h9 | 0.300 秒 | 8,340 | 8,587 | 0.777 |
| 绿梁 h1 | 0.033 秒 | 1,750 | 1,784 | 0.417 |
| 绿梁 h9 | 0.300 秒 | 8,750 | 9,448 | 0.725 |

相邻 h1 的原始状态中，黄条窗口相对初态有 96 个初态格点不再占据、85 个新占据格点；绿梁窗口分别为 116 和 150 个。这是状态编码后的世界格点集合变化，可能混合了物体和手部运动、遮挡以及编码波动，**不是对物理 Gaussian 的逐个追踪或位移测量**。

对 memory，先将同一世界格点上的多个 token 的 64 维特征分别求平均，再计算两组均值的差异 RMS；表中的相对值以两组均值的合并 RMS 为尺度。这个值不受 token 行顺序影响，但平均会丢失 token 分布信息，也不应解释成动作强度、准确率或信息量百分比。

结果能确认两种输入在这两个窗口中并非相同，且较远前缀的上述差异更明显；**不能据此证明 Q-Former 已学会利用未来信息**。当前 memory 结构仍没有为每个 key 单独保存时间字段；正在训练的 Q-Former 及其因果性、重建和运动／静止控制需要独立评估。[全部逐步数据](result/AUDIT.json)

本地和服务器 CPU 测试覆盖了行顺序不变性、重复 token、缺失格点与非有限值检查；实际数据使用相同缓存和 Q 试验配置哈希。分析只读取缓存，不使用 GPU、没有模型更新，也没有向训练进程发送信号。

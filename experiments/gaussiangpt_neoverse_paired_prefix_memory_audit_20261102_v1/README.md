# 运动／静止因果前缀 memory 输入审计

针对当前两窗口 Q-Former 试验，直接读取已绑定的冻结缓存，比较真实运动前缀和重复 S0 前缀在 h1–h9 的输入差异；不加载模型或使用 GPU。稀疏状态与 memory token 都按整数世界格点对齐，报告占据变化、世界格点集合重叠、每格 token 数分布差异，以及共享格点的平均 64 维特征差。不会按稀疏数组行号相减。

每格平均会丢失 token 的部分分布信息；观察到输入差异只能说明两种输入并非相同，不能证明 Q-Former 学会了利用差异，也不能视为运动重建、时间语义或跨视频泛化成功。前缀 memory 的独立时间标签仍需按原架构实际定义判断。

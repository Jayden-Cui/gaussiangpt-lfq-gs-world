# 固定原 decoder 的静止自由码：540 步结果

两个历史训练窗口各有 9 个未来时刻；从旧 Q-Former 读取重复 S0 得到的 `[2,9,16]` 码出发，仅优化码，原两窗口 motion decoder、初态条件与 GaussianGPT codec 始终冻结。训练使用 S0 本身及 S0 在各时刻相机下的 codec 渲染作为目标，未使用真实未来状态或图像进行更新。每个窗口／时刻各访问 30 次，共 540 次更新。

| 更新步数 | 对同相机静止参考的运动区域 MAE | 对同相机真实运动参考的运动区域 MAE | 18 帧中更接近静止参考的帧数 |
|---|---:|---:|---:|
| 0 | 0.159765 | 0.029009 | 0 |
| 180 | 0.138169 | 0.057552 | 0 |
| 360 | 0.136704 | 0.073534 | 2 |
| 540 | **0.131698** | **0.077694** | **3** |

两个参考和两种预测在同一初态与目标时刻相机下生成；运动区域权重由真实运动 codec 参考与静止 codec 参考之差计算，真实未来只用于离线评估。最终静止参考误差较起点降低约 17.57%，说明优化后的码确实改变了输出；但 15／18 帧仍更接近运动参考，不能把下降的误差当成静止控制成功。

## 逐帧画面

检查两个窗口 h1–h9：黄色条在早期仍随手抬起，后期变细或消失，手部出现明显黑色拖影；绿色横梁在部分早期帧仍移动，后期消失并出现大片黑色残影。末时刻的结果可能比运动参考更接近静止参考，但运动物体没有稳定保留，所以**本次没有得到可用的静止码**。

[黄条三栏视频](result/visual_review/s035_source_static_optimized_5fps.mp4)｜[绿梁三栏视频](result/visual_review/s123_source_static_optimized_5fps.mp4)：左为源视频，中为同相机 S0 的静止 codec 参考，右为优化后静止码解码；只含 9 个未来帧，以 5 fps 播放。另有[黄条逐帧图](result/visual_review/s035_static_old_optimized_contact.png)和[绿梁逐帧图](result/visual_review/s123_static_old_optimized_contact.png)，每组左至右为静止参考、旧重复初态 Q 码、优化后的静止码。

第 0 步复现旧静止对照的最大逐项误差为 2.24×10⁻⁷；三份码检查点及最终汇总的哈希均已核验。GPU 峰值已分配显存约 8.03 GiB，实际运行约 274 秒。此次仅覆盖两个已训练窗口、一种初始化和有限优化预算，没有训练 Q-Former、没有独立 GS 冷重放；结果不能证明 decoder 在数学上不可能表达静止，也不能外推全片段或跨视频。

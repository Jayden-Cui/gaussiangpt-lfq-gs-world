# 两窗口双未来 Q-Former：第 600 步独立码重算

第 600 步是蒸馏阶段结束的中间检查点，decoder 仍为固定的双未来自由码教师。独立 CPU 进程重新加载该 Q-Former 权重，分别读取两个窗口的真实运动前缀与重复 S0 前缀；四组 `[9,16]` 连续码均为重新计算，并与绑定的教师码比较。

| 训练窗口 | 运动码相对教师的归一化 MSE | 静止码相对教师的归一化 MSE | Q 的运动／静止码差异 RMS |
|---|---:|---:|---:|
| 黄条 | 1.06×10⁻⁶ | 3.61×10⁻⁶ | 0.21885 |
| 绿梁 | 8.21×10⁻⁶ | 3.32×10⁻⁶ | 0.24273 |

归一化尺度是四组固定教师码的整体平方均值 0.02275；由于 decoder 固定，这些码处在同一个数值坐标系中。码数值差异本身不能证明物理动作语义。

独立 CPU 重算的 18 个逐时刻运动／静止码差异，与此前 GPU 评估记录的最大差为 **1.79×10⁻⁷**。对两个窗口分别扰动 h3 或 h7 之后的**缓存前缀 memory**，更早的码最大变化为 0；该检查不替代正式训练结束后对原始未来状态的因果扰动测试。

绑定的 GPU 中间评估中，Q 运动区域 MAE 为 0.031389，自由码教师为 0.031369；Q 静止参考误差为 0.007585，教师为 0.007583。运动、静止两分支均有 18／18 帧更接近各自参考。这支持 Q 在**两个已训练窗口**中拟合两套自由码，但该独立 CPU 检查不渲染画面、不做 GS 冷重放，也不能证明未见场景泛化或最终联合训练结果。[独立码数据](result/REPLAY.json)｜[原 GPU 中间评估](../gaussiangpt_neoverse_two_future_qformer_20261102_v1/result/step_00600/EVALUATION.json)

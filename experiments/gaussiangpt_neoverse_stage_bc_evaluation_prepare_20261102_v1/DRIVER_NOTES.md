# 阶段 C 的评估执行准备

`c_evaluate.py` 准备从完成的固定教师训练检查点恢复 C0／C1／C2，核对教师收据、decoder 和后验权重后，导出完整窗口后验码及重复初态码，执行因果扰动、同初态运动／静止对照、完整渲染指标和两个关键窗口回归。原生 GS 冷重放在独立进程执行。

运动／静止对照复用同一初态、同一相机、原有时间点和冻结 codec：运动目标来自真实未来状态，静止目标来自同一个初态在相同相机下的渲染。报告四种目标／码组合误差和逐 horizon 码差，不以零码作为唯一对照。

`DRIVER_TEST.json` 是合成小图上的 CPU 逻辑见证，确认正确动作码与静止码分别匹配对应目标、相机相同，以及重放入口不导入 codec。尚未对真实 C checkpoint 运行 GPU、完整评估或原生 GS 重放；两个新增脚本的哈希由该记录单独绑定，正式实验应复制到新目录统一锁定。

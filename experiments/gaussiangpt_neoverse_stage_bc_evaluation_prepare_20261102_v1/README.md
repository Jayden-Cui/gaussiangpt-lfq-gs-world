# 固定教师后的后验评估准备

该代码为 C0、C1、C2 准备同一评估口径：正确后验码、同一后验读取重复初态得到的码、相邻窗口的码、真实未来状态 codec 参考，以及同一个冻结 decoder 的自由码教师。每种码均独立送入 decoder，避免重复阶段 A 的对照别名错误。

在复制教师指标前，评估器核对完整 1512 个窗口／未来步、教师码文件、decoder 参数摘要、codec、状态缓存和评估文件哈希。输出包括 176 个物理未来帧等权和每个窗口等权指标、关键窗口图像与不带顶部文字的原视频／重建视频，以及原生 GS 保存与重放所需文件。

`posterior_eval_core.py` 提供因果前缀扰动、同初态运动／静止分支，以及后验相对教师的总体和 h9 误差比较；这些工具只有在真实教师和训练完成的后验模型出现后才能作科学验收。默认的 1.10 倍只作为数值门槛，主要物体轨迹、姿态和运动画面仍需审查。当前没有运行正式阶段 C 评估。

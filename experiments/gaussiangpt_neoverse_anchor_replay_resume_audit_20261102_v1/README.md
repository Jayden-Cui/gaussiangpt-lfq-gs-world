# 回放训练扩展前的优化器与采样审计

正在运行的五轮回放实验只有通过全片段和关键动作检查，才考虑扩展训练。本项只做 CPU 审计，不会更改或恢复正在运行的模型。

检查两点：

1. 按当前确定性采样器生成五轮和二十轮，确认前五轮逐项相同；如果将来扩展，剩余是 15 轮、6345 次 B4 更新，不能重新从第一轮开始计数。
2. 使用已完成的原阶段 B 第 20 轮 checkpoint，按同一 `optimizer_for` 和 168 项自由码顺序重建 Adam，核对矩、步数和参数组，再在两个独立副本上执行一次合成梯度更新，验证未选窗口不会因旧动量变化。

此检查使用**历史 B checkpoint**，不是当前回放实验的 checkpoint；若将来选择扩展，必须再单独验证回放第 5 轮模型、码、优化器、数据和评估绑定。历史 checkpoint 没有保存完整随机数状态，且当前 MinkowskiEngine 配置不保证确定性，因此不能声称 GPU 后续轨迹逐位完全相同。结果不作为动作质量或教师验收依据。

# 阶段 B 两窗口早期回归检查

为避免全片段平均值掩盖已知动作退化，本工具在空闲 GPU 上读取阶段 B 的不可变第 5、10 轮成对 checkpoint，单独渲染原先成功的黄条、绿梁两个窗口；每个窗口包括首帧和全部 9 个未来帧，并与原两窗口自由码结果按相同运动 MAE 口径比较。它不更新训练中的模型或码，不占训练 GPU，且不自动判断动作是否成功。

`warm` 直接读取阶段 B 启动时绑定的原两窗口 decoder 与真实初始码；要求两个窗口的运动 MAE 与历史原始评估一致，作为实际渲染链路测试。第 5、10 轮结果只是早期回归诊断，不替代全部 168 窗口正式评估、人工动态审查和独立 GS 重放；本工具本身不进行原生 GS 包冷重放。视频左侧为源视频，右侧为自由码重建，以 5 fps 慢放，没有顶部标记。

`watcher.py` 使用 Linux 文件关闭事件等待完整 checkpoint，使用进程退出事件判断训练是否中止；只启动独立预览进程，不向训练进程发送信号。预览失败会留下错误记录并停止预览，不影响或自动重试训练。
